# TI 2026 Fantasy Lab

На странице пять независимых разделов: прогноз состава на выбранный игровой день, полное предсказание плей-офф (`#playoffs`), отдельное фэнтези по классической шкале Dota с фактическими эмблемами (`#dota-fantasy`), статистика отдельных показателей классических правил (`#dota-rules`) и интерактивная карта Observer/Sentry (`#ward-map`).

Ward Map лениво загружает отдельный `ward-data.js` (~8,48 MiB), рисует агрегаты сетки 64 × 64 на `<canvas>` и не добавляет исходные 137 671 событие в основной `data.js`. Для режима устойчивых интересных точек payload дополнительно хранит квантизованные центроиды групп: при zoom кластеры пересчитываются на сетках 64 × 64, 128 × 128 и 256 × 256 и распадаются на более точные места. Доступны прежние фильтры, сравнение игроков и нормализация по абсолютному числу, player-maps или player-minutes. Unique matches, player-maps и player-minutes показаны отдельно; сравниваемые слои используют общую цветовую шкалу или шкалу размера точек.

Canvas масштабируется от 1× до 4× колёсиком, double-click или кнопками и перемещается pointer drag мышью либо пальцем. Zoom/pan меняют только viewport и не запускают повторную фильтрацию или агрегацию.

Карта использует разные координатные подложки для patch id 59 (Dota 2 7.40) и 60 (7.41). Подложка 7.41 — детальный ортографический рендер полной клиентской 3D-сцены 3072 × 3072, а не HUD-minimap. При смешении патчей raster автоматически отключается и остаётся нейтральная сетка. Материалы Dota 2 принадлежат Valve и используются только внутри некоммерческой аналитической fan-work визуализации; происхождение, хеши, атрибуция и ограничения описаны в `WARD_MAP_ASSETS.md`. Формулы и patch-конфигурация lifetimes описаны в `../docs/WARD_MAP_METHODOLOGY.md` и `../docs/WARD_MAP_SPEC.md`.

URL критичных ресурсов Ward Map содержат общий cache-busting version: HTML, renderer, payload и patch-карты не должны смешиваться между релизами в браузерном кэше.

Статический дашборд по игрокам The International 2026.

- статистика групповых стадий Tier-1 турниров 2026 года;
- общий пул коров позиций 1/3;
- отдельный пул мидеров;
- общий пул саппортов позиций 4/5;
- итоговые очки включают базу по всем доступным показателям и прирост активных аспектов;
- рейтинг малых выборок скорректирован усадкой `n / (n + 20)`.

Данные на странице не содержат API-ключей и загружаются локально из `data.js`.

В `#dota-fantasy` есть отдельный топ эмблем по каждой категории и три
конструктора комплектов. Пользователь выбирает пять эмблем, вводит процент с
карточки по шкале от нуля и получает пересчитанный рейтинг. Core и support
ранжируются парами одной команды по сумме двух игроков, mid — индивидуально.
Топы разделены по цветам. В том же разделе опубликован отдельный разбор
смотрителей (позиционная оценка по 20 player-map) и Терзателя (фактические
события 109 карт TI); оценочные значения визуально помечены.
