# TI 2026 Fantasy Lab

На странице четыре независимых раздела: прогноз состава на выбранный игровой день, полное предсказание плей-офф (`#playoffs`), статистика по классическим правилам Dota (`#dota-rules`) и интерактивная карта Observer/Sentry (`#ward-map`).

Ward Map лениво загружает отдельный `ward-data.js` (~6,94 MiB), рисует агрегаты сетки 64 × 64 на `<canvas>` и не добавляет исходные 137 671 событие в основной `data.js`. Доступны прежние фильтры и сравнение игроков, а также нормализация по абсолютному числу, player-maps или player-minutes. Unique matches, player-maps и player-minutes показаны отдельно; сравниваемые слои используют общую цветовую шкалу.

Растровая подложка не используется: свободная лицензия на координатно корректный minimap патчей 59/60 не подтверждена, поэтому интерфейс показывает нейтральную координатную сетку. Методология, patch-конфигурация lifetimes, атрибуция проверенных источников и контрольные формулы описаны в `../docs/WARD_MAP_METHODOLOGY.md` и `../docs/WARD_MAP_SPEC.md`.

Статический дашборд по игрокам The International 2026.

- статистика групповых стадий Tier-1 турниров 2026 года;
- общий пул коров позиций 1/3;
- отдельный пул мидеров;
- общий пул саппортов позиций 4/5;
- итоговые очки включают базу по всем доступным показателям и прирост активных аспектов;
- рейтинг малых выборок скорректирован усадкой `n / (n + 20)`.

Данные на странице не содержат API-ключей и загружаются локально из `data.js`.
